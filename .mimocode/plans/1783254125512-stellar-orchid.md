# Savings Withdrawal — Approval-Based Flow with Penalty Enforcement

## Goal
Staff initiates a savings withdrawal → manager/executive approves/rejects. Premature penalty (before maturity) is auto-deducted. Uses the existing `pending_approvals` table (type `'withdrawal'`).

---

## Architecture

```
Staff taps Withdraw on savings detail
  → Shows WithdrawDialog (amount, payment mode, penalty preview)
  → Inserts into pending_approvals (type: 'withdrawal', status: 'pending')
  → Shows snackbar "Withdrawal request submitted for approval"

Manager sees pending withdrawal in approval queue
  → Reviews amount, penalty, payment mode
  → Approves: creates savingsWithdrawal transaction + updates plan balance
  → Rejects: marks as rejected with reason
```

## Step 1: Repository Methods (`savings_repository.dart`)

### `submitWithdrawalRequest()`
```dart
Future<void> submitWithdrawalRequest({
  required String savingsPlanId,
  required double amount,
  required String paymentMode, // 'cash', 'upi', 'bank_transfer'
  required String memberId,
  String? notes,
}) async {
  final client = _client;

  // 1. Fetch the savings plan to get current balance and penalty info
  final plan = await client.from('savings_plans')
      .select('current_amount, premature_penalty, maturity_date, status')
      .eq('id', savingsPlanId).maybeSingle();

  if (plan == null) throw Exception('Savings plan not found');
  if (plan['status'] != 'active') throw Exception('Cannot withdraw from inactive vault');

  final currentBalance = (plan['current_amount'] as num?)?.toDouble() ?? 0;
  if (amount > currentBalance) throw Exception('Insufficient balance (available: ₹$currentBalance)');

  // 2. Calculate premature penalty if before maturity
  final maturityDate = DateTime.parse(plan['maturity_date']);
  final penaltyPercent = (plan['premature_penalty'] as num?)?.toDouble() ?? 0;
  final isPremature = DateTime.now().isBefore(maturityDate);
  final penaltyAmount = isPremature ? (amount * penaltyPercent / 100) : 0.0;

  // 3. Fetch branch_id from member
  final member = await client.from('members')
      .select('branch_id').eq('id', memberId).maybeSingle();
  final branchId = member?['branch_id'] as String?;

  // 4. Insert into pending_approvals
  await client.from('pending_approvals').insert({
    'org_id': _orgId,
    if (branchId != null) 'branch_id': branchId,
    'type': 'withdrawal',
    'member_id': memberId,
    'requested_by': (await client.auth.currentUser())?.id,
    'status': 'pending',
    'notes': notes,
    // Store withdrawal details as JSON in metadata or notes
  });

  // Also store details in a more structured way — use metadata JSONB column
  // (if the extended schema from branch_manager_migration.sql is applied)
  // OR encode in the notes field as JSON
}
```

### `approveWithdrawal()`
```dart
Future<void> approveWithdrawal({
  required String approvalId,
  required String reviewedById,
  String? rejectionReason,
  bool approve = true,
}) async {
  final client = _client;

  // 1. Fetch the pending approval
  final approval = await client.from('pending_approvals')
      .select('*').eq('id', approvalId).maybeSingle();
  if (approval == null) throw Exception('Approval not found');

  // 2. Update status
  await client.from('pending_approvals').update({
    'status': approve ? 'approved' : 'rejected',
    'notes': rejectionReason ?? approval['notes'],
  }).eq('id', approvalId);

  // 3. If approved, execute the withdrawal
  if (approve) {
    // Parse withdrawal details from notes (JSON)
    // Create transaction: type='savingsWithdrawal', amount, payment_mode
    await client.from('transactions').insert({
      'savings_id': approval['member_id'], // needs actual savings_plan_id
      'amount': withdrawalAmount,
      'type': 'savingsWithdrawal',
      'payment_mode': paymentMode,
      'member_id': approval['member_id'],
      'org_id': _orgId,
      'description': 'Savings withdrawal (approved)',
      'transaction_date': DateTime.now().toIso8601String(),
    });

    // Update plan balance
    await recalculateBalance(savingsPlanId);
  }
}
```

### Provider
```dart
final withdrawalApprovalsProvider = FutureProvider.autoDispose<List<Map<String, dynamic>>>((ref) async {
  final client = ref.watch(supabaseClientProvider);
  final user = ref.watch(currentUserProvider);
  if (user == null) return [];

  // Branch managers see only their branch; exec admins see all in org
  var query = client.from('pending_approvals')
      .select('*, members:member_id(full_name, phone), profiles:requested_by(full_name)')
      .eq('org_id', user.orgId!)
      .eq('type', 'withdrawal')
      .order('created_at', ascending: false);

  if (user.role == 'branchManager' && user.branchId != null) {
    query = query.eq('branch_id', user.branchId);
  }

  return (await query) as List<Map<String, dynamic>>;
});
```

## Verification

1. **Staff flow**: Open savings detail → tap Withdraw → enter amount → see penalty → submit → snackbar confirmation
2. **Manager flow**: Open withdrawal queue → see pending request → approve → transaction created, balance updated
3. **Rejection flow**: Manager rejects with reason → status updated, staff sees rejection
4. **Penalty enforcement**: Withdraw before maturity → penalty auto-calculated and deducted
5. **Edge cases**: Withdraw exact balance (closes vault?), withdraw more than balance (blocked), withdraw from paused vault (blocked)
6. **Route navigation**: Savings page app bar → withdrawal queue → back
7. **Badge count**: Pending count shows on the queue entry point
