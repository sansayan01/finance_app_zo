# Advanced Filtering for TransactionsPage

## Goal
Add date range, amount range, payment mode, sort, active filter badge, and expand/collapse to the Transaction History page.

## Files to Create

### 1. `lib/features/transactions/data/models/transaction_filter.dart` (~100 lines)
Immutable filter model following the `CustomerTransactionFilter` pattern:
```dart
class TransactionFilter {
  final String searchQuery;
  final TransactionType? type;
  final List<PaymentMode> paymentModes;
  final DateTime? dateFrom;
  final DateTime? dateTo;
  final double? amountMin;
  final double? amountMax;
  final String sortBy; // 'date_desc' | 'date_asc' | 'amount_desc' | 'amount_asc'

  int get activeFilterCount { ... }
  bool get hasActiveFilters => activeFilterCount > 0;
  TransactionFilter copyWith({ ... }) { ... }
  TransactionFilter clearAll() => const TransactionFilter();
}
```

### 2. `lib/features/transactions/presentation/widgets/transaction_filter_panel.dart` (~400 lines)
Two widgets:
- **TransactionFilterBar**: Search TextField + tune icon with active-filter count badge
- **AdvancedTransactionFilters**: Collapsible panel with:
  - Date range: From/To via `PremiumCalendarSheet.show()` + quick presets (This Week, This Month, Last 30 Days)
  - Amount range: Min/Max text fields
  - Payment mode: Multi-select chips (Cash, UPI, Bank, Cheque, Card)
  - Sort: Dropdown (Newest, Oldest, Amount high-low, Amount low-high)
  - "Clear All" button
- Uses `SizeTransition` + `FadeTransition` for expand/collapse animation

## Files to Modify

### 3. `lib/features/transactions/data/repositories/transactions_repository.dart`
Add parameters to `getTransactionsPaginated`:
- `DateTime? dateFrom` → `.gte('created_at', ...)`
- `DateTime? dateTo` → `.lte('created_at', endOfDay)`
- `double? amountMin` → `.gte('amount', ...)`
- `double? amountMax` → `.lte('amount', ...)`
- `List<PaymentMode>? paymentModes` → `.inFilter('payment_mode', ...)`
- `String sortBy = 'date_desc'` → dynamic `.order()` clauses

### 4. `lib/features/transactions/presentation/pages/transactions_page.dart`
- Replace `_filterType` and `_searchQuery` with `TransactionFilter _filter`
- Add `_isFilterExpanded` toggle
- Wire existing type chips to `_filter.type`
- Insert `TransactionFilterBar` and `AdvancedTransactionFilters` in the build method
- Pass all filter fields to `_loadPage()` → repository

## Implementation Order

## Edge Cases
- Date range: use end-of-day (23:59:59) for `dateTo`
- Sort by amount: add secondary sort by `created_at DESC` for stable ordering
- Payment mode NULL: `.inFilter` naturally excludes NULLs
- Amount validation: `double.tryParse`, ignore invalid
- Bulk delete: independent of filter state, no changes needed
- Search debounce: 300ms generation-counter pattern
