# Upgrade Savings Statement PDF

## Overview
Improve the savings passbook statement to match the premium quality of the portfolio statements we built. Three key changes: premium centered org header, add overdue section, compact layout.

---

## File to Modify

### `lib/features/savings/data/services/savings_statement_pdf_service.dart`

## Changes

### 1. Premium Centered Org Header (lines 117-180)

Replace the current left-aligned header with a centered, premium header:

```dart
static pw.Widget _buildHeader(...) {
  return pw.Column(
    crossAxisAlignment: pw.CrossAxisAlignment.center,
    children: [
      // Logo (50px, centered)
      if (org.logoBytes != null && _isValidImage(org.logoBytes))
        pw.Container(height: 50, child: pw.Image(pw.MemoryImage(org.logoBytes!))),
      if (org.logoBytes != null) pw.SizedBox(height: 10),
      
      // Org name (22px, centered, letter spacing)
      pw.Center(child: pw.Text(org.name, style: pw.TextStyle(
        fontSize: 22, fontWeight: pw.FontWeight.bold,
        letterSpacing: 1, color: PdfColors.blueGrey900,
      ))),
      pw.SizedBox(height: 4),
      
      // Address (centered)
      if (org.fullAddress.isNotEmpty) pw.Center(child: pw.Text(org.fullAddress, ...)),
      
      // Phone | Email (centered)
      if (org.phone != null || org.email != null) pw.Center(child: pw.Text(...)),
      
      // QR code (centered, if available)
      if (qrPngBytes != null) pw.Center(child: ...),
      
      pw.SizedBox(height: 16),
      pw.Container(height: 2, color: PdfColors.blueGrey900),
      pw.SizedBox(height: 12),
      
      // Statement title and period
      pw.Row(
        mainAxisAlignment: pw.MainAxisAlignment.spaceBetween,
        children: [
          pw.Text('SAVINGS PASSBOOK STATEMENT', ...),
          pw.Text('${_date(periodStart)} - ${_date(periodEnd)}', ...),
        ],
      ),
    ],
  );
}
```

### 3. Update caller in saving_detail_page.dart

Pass the overdue amount when calling `SavingsStatementPdfService.build()`:
```dart
// Calculate overdue from schedule
final schedule = await ref.read(savingsScheduleProvider(saving.id).future);
final today = DateTime(now.year, now.month, now.day);
final overdueInstallments = schedule
    .where((i) => !i.isPaid && !i.isFrozen && i.dueDate.isBefore(today))
    .toList();
final overdueAmount = overdueInstallments.fold<double>(0.0, (sum, i) => sum + i.amount);

// Pass to build
bytes = await SavingsStatementPdfService.build(
  data: statementData,
  org: org,
  statementRef: statementRef,
  generatedByName: ref.read(currentUserProvider)?.fullName,
  overdueAmount: overdueAmount,
);
```
