# Deploy Capital / New Loan Form - Enhancement Suggestions

## Current Form Features
- Borrower selection
- Principal amount (with slider)
- Interest type (Rate % or Amount ₹) with basis options (daily/weekly/monthly/yearly/on principal)
- Tenure (value + unit: days/weeks/months/years)
- Collection frequency (daily/weekly/monthly/yearly)
- Interest logic (reducing balance / flat)
- First installment date
- Migration toggle for existing loans
- Financial summary sidebar
- Amortization preview

---

## Suggested Additions (Prioritized)

### Phase 1: Essential (High Impact)

**1. Loan Purpose / Category**
- Dropdown: Business, Personal, Education, Agriculture, Medical, Emergency, Asset Purchase, Other
- Helps with analytics, reporting, and risk assessment
- Simple dropdown field in Facility Details section

**2. Processing Fee**
- One-time fee deducted from disbursement or added to loan
- Toggle: Flat ₹ or % of principal
- Auto-calculates net disbursement amount
- Shows in financial summary

**3. Grace Period**
- Number of days/weeks before first EMI starts
- Useful for business loans where income takes time to generate
- Auto-adjusts first installment date
- Shows in amortization preview

**4. Disbursement Method**
- Dropdown: Cash, Bank Transfer, UPI, Mobile Wallet, Cheque
- Text field for transaction reference/UTR number
- Important for audit trail and reconciliation

**5. Internal Notes / Remarks**
- Multi-line text field for underwriting notes
- Not visible to borrower
- Stored in database for future reference

### Phase 2: Important (Medium Impact)

**6. Auto-assign Collector**
- Dropdown to assign field staff for collection
- Filter by borrower's zone/area
- Shows collector's current workload
- Integrates with existing staff profiles

**7. Penalty Configuration**
- Late payment penalty: Flat ₹ or % per day/week
- Grace days before penalty applies
- Shows in loan terms summary

**8. Prepayment Terms**
- Toggle: Allow early closure (Yes/No)
- Prepayment penalty: Flat ₹ or % of outstanding
- Important for borrower flexibility

**9. Guarantor / Co-borrower**
- Search and select existing customer as guarantor
- Name, phone, relationship fields
- Multiple guarantors support

### Phase 3: Advanced (Lower Priority)

**10. Collateral / Security**
- Type: Property, Vehicle, Gold, Equipment, Other
- Description, estimated value
- Photo attachment placeholder

**11. Insurance Linkage**
- Credit life insurance toggle
- Premium amount (flat or % of loan)
- Added to total exposure

**12. Repayment Holiday**
- Select dates to skip EMIs (festivals, seasonal)
- Auto-adjusts schedule
- Useful for agricultural loans

**13. Document Upload**
- Loan agreement PDF
- KYC documents
- Photo of borrower/shop
- Signature capture

**14. Loan Template**
- Pre-saved configurations (e.g., "Standard Personal Loan", "Business Loan")
- One-click apply
- Speeds up deployment for common loan types

## Database Changes Needed

```sql
ALTER TABLE public.loans ADD COLUMN IF NOT EXISTS loan_purpose TEXT;
ALTER TABLE public.loans ADD COLUMN IF NOT EXISTS processing_fee DECIMAL(12, 2) DEFAULT 0;
ALTER TABLE public.loans ADD COLUMN IF NOT EXISTS processing_fee_type TEXT DEFAULT 'flat';
ALTER TABLE public.loans ADD COLUMN IF NOT EXISTS grace_period_days INTEGER DEFAULT 0;
ALTER TABLE public.loans ADD COLUMN IF NOT EXISTS disbursement_method TEXT;
ALTER TABLE public.loans ADD COLUMN IF NOT EXISTS disbursement_reference TEXT;
ALTER TABLE public.loans ADD COLUMN IF NOT EXISTS internal_notes TEXT;
ALTER TABLE public.loans ADD COLUMN IF NOT EXISTS assigned_collector_id UUID REFERENCES public.profiles(id);
ALTER TABLE public.loans ADD COLUMN IF NOT EXISTS penalty_rate DECIMAL(5, 2) DEFAULT 0;
ALTER TABLE public.loans ADD COLUMN IF NOT EXISTS penalty_type TEXT DEFAULT 'flat';
ALTER TABLE public.loans ADD COLUMN IF NOT EXISTS allow_prepayment BOOLEAN DEFAULT true;
ALTER TABLE public.loans ADD COLUMN IF NOT EXISTS prepayment_penalty DECIMAL(5, 2) DEFAULT 0;
ALTER TABLE public.loans ADD COLUMN IF NOT EXISTS guarantor_id UUID REFERENCES public.members(id);
```
