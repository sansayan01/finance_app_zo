# UPI QR Code Integration in Quick Collect (CollectionSheet)

## Goal
When a collection agent/manager/admin selects UPI as the payment mode in the CollectionSheet, display an inline QR code. After the customer pays by scanning, the agent taps "Payment Successful" to log the transaction directly (no pending verification flow).

## Workflow
1. Agent opens Quick Collect → selects EMIs/savings → taps **UPI** payment mode chip
2. A QR code panel appears **inline** (below the payment mode chips, replacing the Collect button area)
3. Customer scans QR → pays via their UPI app
4. Agent verifies payment received → taps **"Payment Successful"**
5. Transaction + collection records are created with `payment_mode: 'upi'` → sheet closes

## Key Difference from Existing UpiPaymentSheet
The existing `UpiPaymentSheet` is a **customer self-service** flow — it creates `upi_payment_requests` records with `status: 'pending'` that staff must confirm later. The new flow is **staff-initiated** — the agent generates the QR, verifies payment visually, and logs it immediately as a completed collection. No pending request queue.

## Detailed Implementation

### State additions (in `_CollectionSheetState`):
```dart
bool _showUpiQr = false;
String? _upiVpa;
String? _upiMerchantName;
Uint8List? _upiQrBytes;
String? _upiUri;
bool _isProcessingUpi = false;
bool _upiLoadError = false;
```

### `_loadUpiConfig()` method:
```dart
Future<void> _loadUpiConfig() async {
  try {
    final upiService = ref.read(upiServiceProvider);
    final vpaData = await upiService.getOrgVpa();
    if (vpaData == null || !mounted) { setState(() => _upiLoadError = true); return; }
    final vpa = vpaData['upi_vpa'] as String?;
    final merchant = vpaData['merchant_name'] as String? ?? '';
    if (vpa == null || vpa.isEmpty) { setState(() => _upiLoadError = true); return; }
    
    final totalAmount = _totalAmount;
    final note = widget.mode == CollectionMode.savings
        ? 'Savings ${widget.savingsPlan?.planName ?? ""}'
        : 'Loan ${widget.loan?.loanNumber ?? ""} EMI';
    final uri = UpiService.buildUpiUri(vpa: vpa, amount: totalAmount, merchantName: merchant, transactionNote: note);
    final qr = await QrPng.generate(uri, size: 250);
    
    if (mounted) setState(() { _upiVpa = vpa; _upiMerchantName = merchant; _upiUri = uri; _upiQrBytes = qr; });
  } catch (_) { if (mounted) setState(() => _upiLoadError = true); }
}
```

### UPI chip tap modification:
```dart
onTap: () {
  setState(() => _selectedMode = mode);
  if (mode == 'upi') {
    setState(() => _showUpiQr = true);
    if (_upiVpa == null) _loadUpiConfig();
  } else {
    setState(() => _showUpiQr = false);
  }
},
```

### `_buildUpiQrSection()` widget:
- Shows loading spinner while QR generates
- Shows error state with retry if VPA not configured
- Shows QR image + VPA label + "Open UPI App" button + "Payment Successful" button
- "Payment Successful" button calls `_confirmUpiAndSubmit()`

### `_confirmUpiAndSubmit()` method:
```dart
Future<void> _confirmUpiAndSubmit() async {
  setState(() => _isProcessingUpi = true);
  try {
    await _submit(); // existing method — uses _selectedMode = 'upi'
    if (mounted) Navigator.pop(context);
  } catch (e) {
    if (mounted) ScaffoldMessenger.of(context).showSnackBar(...);
  } finally {
    if (mounted) setState(() => _isProcessingUpi = false);
  }
}
```

### Action buttons visibility:
When `_showUpiQr` is true, replace the bottom action row with just the Cancel button (the QR section has its own "Payment Successful" CTA). When false, show normal Cancel + Collect buttons.
