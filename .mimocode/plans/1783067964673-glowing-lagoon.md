# Add "Today" Button to Quick Collect Calendar

## Context
The user wants a "Today" button in the Quick Collect page's "Select Payment Dates" calendar. When tapped, it should jump the calendar to today's date automatically. This is useful when the user is viewing a different month and wants to quickly return to today.

The calendar is implemented in two files:
- `lib/features/loans/presentation/widgets/emi_payment_selector.dart` (EMI/loan payments)
- `lib/features/savings/presentation\widgets/savings_payment_selector.dart` (savings payments)

Both use `table_calendar` with a local `focusedDay` variable that controls which month is displayed.

## Implementation

### Files to Modify
1. `lib/features/loans/presentation/widgets/emi_payment_selector.dart`
2. `lib/features/savings\presentation\widgets\savings_payment_selector.dart`

### Changes

**In both files, add a "Today" button in the header section:**

The header currently has: `[Calendar Icon] [Title + Count] [Clear Button]`

Add a "Today" button between the title and the Clear button (or next to Clear):

```dart
// Today button - jump to today's date
GestureDetector(
  onTap: () {
    HapticFeedback.selectionClick();
    setPopupState(() {
      focusedDay = DateTime.now();
    });
  },
  child: Container(
    padding: const EdgeInsets.symmetric(horizontal: 10, vertical: 6),
    decoration: BoxDecoration(
      gradient: LinearGradient(colors: [
        _primaryColor().withValues(alpha: 0.12),
        _primaryColor().withValues(alpha: 0.06),
      ]),
      borderRadius: BorderRadius.circular(10),
      border: Border.all(
        color: _primaryColor().withValues(alpha: 0.2),
      ),
    ),
    child: Row(
      mainAxisSize: MainAxisSize.min,
      children: [
        Icon(Icons.today_rounded, size: 13, color: _primaryColor()),
        const SizedBox(width: 4),
        Text(
          'Today',
          style: TextStyle(
            fontSize: 12,
            fontWeight: FontWeight.w700,
            color: _primaryColor(),
          ),
        ),
      ],
    ),
  ),
),
```

**Location in emi_payment_selector.dart:** After line 953 (after the Clear button closing), add the Today button.

**Location in savings_payment_selector.dart:** After line 938 (after the Clear button closing), add the Today button.

### Behavior
- When "Today" is tapped, `focusedDay` is set to `DateTime.now()`
- The calendar jumps to display the current month
- Haptic feedback on tap
- Button is always visible (not conditional on selection state)
- Styled with primary color to match existing UI patterns
