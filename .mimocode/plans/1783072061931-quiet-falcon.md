# Plan: Compact Deposit History with Internal Scroll + View All

## Context
The customer savings detail page (`customer_savings_detail_page.dart`) currently shows the last 5 contributions as a flat `SliverList` inside the parent `CustomScrollView`. This makes the section take up variable height and there's no way to see older transactions. The user wants a **compact fixed-height section** (5 items tall) that scrolls internally, plus a **"View All" button** to see all transactions.

## File to Modify
- `lib/features/customer_portal/presentation/pages/customer_savings_detail_page.dart`

## Changes

### 1. Replace the `SliverList` with a compact scrollable container (lines 1036-1053)

**Current**: `SliverList` with `SliverChildBuilderDelegate` rendering `recent` (last 5) directly in the parent scroll.

**New**: `SliverToBoxAdapter` wrapping a fixed-height `SizedBox` containing a `ListView.separated` that shows ALL transactions with internal scrolling.

- Height: `5 × (~80px tile + 6px separator) ≈ 430px`
- `ListView.separated` with `physics: AlwaysScrollableScrollPhysics()` for internal scroll
- `clipBehavior: Clip.hardEdge` for clean cutoff at edges
- Show ALL transactions (remove `.take(5)`) so the user can scroll through the full history

### 2. Add "View All" button below the compact list

Add a `SliverToBoxAdapter` after the compact section with a styled text button:
- Label: "View All Transactions →"
- Style: accent color, bold, matching the page theme
- On tap: navigate to `CustomerTransactionsPage` via `context.push('/customer/transactions')`
- Only show if there are more than 5 transactions

### 3. Loading & error states remain as-is (lines 1000-1019)

No changes needed — the shimmer loading and error states are already `SliverToBoxAdapter` or `SliverList` with fixed child counts.

## Verification
1. Open a customer savings detail page with 5+ transactions
2. The "Recent Contributions" section should be ~430px tall (5 items visible)
3. Scroll inside the section to see older transactions
4. Below the section, "View All Transactions →" should appear
5. Tap "View All" → navigates to the full transactions page
6. If there are ≤5 transactions, no "View All" button shown
7. Check both light and dark themes
