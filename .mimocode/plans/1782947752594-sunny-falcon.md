# Today's Payments Page — Glassmorphic Upgrade

## Goal
Apply the same premium glassmorphic design language from the dashboard to the Today's Payments page — semi-transparent cards, animated background, icon-based section headers, and accent borders.

---

## Current State (from exploration)
- **File**: `lib/features/payments/presentation/pages/today_payments_page.dart` (2893 lines)
- Solid card backgrounds (`AppColors.cardDark` / `Colors.white`)
- No animated background — plain scaffold color
- AppBar uses `BackdropFilter` for frosted glass on scroll (keep this)
- Payment cards use solid shadows and borders
- Hero header has its own gradient + BackdropFilter (keep, already premium)
- 12+ private widgets in the same file

## Target State
- AuroraBackground wrapping the page body
- All payment cards use `GlassCard(glassmorphic: true)` with no BackdropFilter
- Section headers with icon containers (matching dashboard pattern)
- Accent-colored borders on cards
- Tab bar glassmorphic
- Performance-optimized (no extra blur passes)

---

## Implementation Plan

### Step 1: Add AuroraBackground to Page Body
**File**: `today_payments_page.dart`

Wrap the `CustomScrollView` body in `AuroraBackground` (the same widget used on the dashboard). This adds the animated floating circles and gradient blobs behind the content.

Current: `Scaffold(backgroundColor: isDark ? AppColors.backgroundDark : Color(0xFFF5F6FA))`
Change: Keep scaffold transparent, add `AuroraBackground` as the body wrapper.

### Step 2: Convert Payment Cards to Glassmorphic
**File**: `today_payments_page.dart` — `_PaymentCard` widget

Replace the solid `Container` with `GlassCard(glassmorphic: true)`:
- Remove `BoxDecoration(color: isDark ? AppColors.cardDark : Colors.white, ...)`
- Use `GlassCard(glassmorphic: true, padding: ..., borderRadius: 14, onTap: ...)`
- Add subtle accent border: `borderColor: statusColor.withValues(alpha: 0.12)`
- Remove the manual `BoxShadow` (GlassCard handles shadows)

### Step 3: Convert Overdue Cards to Glassmorphic
**File**: `today_payments_page.dart` — `_GroupedOverdueCard` widget

Same treatment as `_PaymentCard`:
- Replace solid Container with `GlassCard(glassmorphic: true)`
- Add overdue-themed accent border

### Step 4: Convert Tab Bar to Glassmorphic
**File**: `today_payments_page.dart` — `_PremiumTabBar` widget

Replace the solid tab bar container:
- Current: `Container(color: isDark ? AppColors.fillDark : Color(0xFFECEEF3))`
- Change: `GlassCard(glassmorphic: true, borderRadius: 16, padding: EdgeInsets.all(4))`
- Keep the tab indicator with primary glow shadow

### Step 5: Add Icon-Based Section Headers
**File**: `today_payments_page.dart` — `_HeroHeader` and tab labels

Add icon containers to match dashboard pattern:
- Hero header: already has gradient, keep as-is
- Tab labels: add small icon next to each tab label (Pending: `Icons.schedule_rounded`, Overdue: `Icons.warning_rounded`, Done: `Icons.check_circle_rounded`)

### Step 6: Add Accent Borders to Active Filters Banner
**File**: `today_payments_page.dart` — `_ActiveFiltersBanner` widget

Replace solid container with glassmorphic:
- Use `GlassCard(glassmorphic: true, borderRadius: 16)`
- Add primary-tinted border

### Step 7: Optimize — No BackdropFilter
**File**: `today_payments_page.dart`

- The AppBar frosted glass already uses BackdropFilter — keep it (only 1 instance, acceptable)
- Remove any other BackdropFilter instances
- Add `RepaintBoundary` around the payment list for scroll performance
