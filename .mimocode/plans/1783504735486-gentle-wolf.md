# Implementation Plan: Integrate Product Templates into Loan & Savings Creation

## Current State
- `loan_products` and `savings_products` tables exist (created in previous phase)
- Product CRUD pages exist in Settings
- BUT the New Loan page (`new_loan_page.dart`) and New Savings page (`new_recurring_saving_page.dart`) do NOT read from product templates
- Staff manually enters all fields every time

## Goal
Add a **"Select Product"** dropdown at the top of both creation flows. When selected, auto-populate fields from the template. Staff can still override any field. Customer selection and migration features remain unchanged.

### Modify: `new_loan_page.dart`

│  SELECT PRODUCT (optional)              │
│  ┌─────────────────────────────────┐    │

│  Personal Loan · 12% reducing · 12mo   │

- Dropdown loads active products from `loanProductsProvider`
- Shows product name + rate + tenure as subtitle
- "None (Manual Entry)" option at top for ad-hoc loans
- When product selected → calls `_applyLoanProduct(product)` which updates the provider state:

```dart
void _applyLoanProduct(Map<String, dynamic> product) {
  final notifier = ref.read(newLoanProvider.notifier);
  
  // Interest mode: map 'reducing' → InterestMode.rate, 'flat' → InterestMode.rate, 'amount' → InterestMode.amount
  if (product['interest_mode'] == 'amount') {
    notifier.updateInterestMode(InterestMode.amount);
    notifier.updateInterestAmount(product['interest_rate'] ?? 0);
  } else {
    notifier.updateInterestMode(InterestMode.rate);
    notifier.updateInterestRate(product['interest_rate'] ?? 0);
  }
  
  // Interest basis: map 'onPrincipal' → InterestBasis.onPrincipal, etc.
  notifier.updateInterestRateBasis(
    InterestBasis.values.firstWhere(
      (e) => e.name == product['interest_basis'],
      orElse: () => InterestBasis.monthly,
    ),
  );
  
  // Interest logic: map 'reducing' → reducingBalance, 'flat' → flat
  notifier.updateInterestLogic(
    product['interest_mode'] == 'flat' 
      ? InterestLogic.flat 
      : InterestLogic.reducingBalance,
  );
  
  // Tenure
  notifier.updateTenureValue(product['tenure_months'] ?? 12);
  notifier.updateTenureUnit(
    TenureUnit.values.firstWhere(
      (e) => e.name == product['tenure_unit'],
      orElse: () => TenureUnit.months,
    ),
  );
  
  // Collection type: map 'monthly' → CollectionType.monthly, etc.
  notifier.updateCollectionType(
    CollectionType.values.firstWhere(
      (e) => e.name == product['frequency'],
      orElse: () => CollectionType.monthly,
    ),
  );
}
```

- Also update the `_rateController`, `_tenureController` text to reflect new values
- Store `selectedProductId` in local state for reference

  // Collection type
  notifier.updateCollectionType(
    CollectionType.values.firstWhere(
      (e) => e.name == product['collection_type'],

    ),
  );

  notifier.updatePrematurePenalty(product['premature_penalty'] ?? 0);
}
