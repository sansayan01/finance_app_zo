# Data Backup & Export Page — Implementation Plan

## Overview
Build an advanced, organization-level Data Backup & Export page for the Executive Admin settings. The page allows full org data backup with format selection, category-level exports, export history tracking, scheduled backups, and advanced options (encryption, compression).

---

## Files to Create (3)

### 1. `lib/features/settings/data/services/backup_export_service.dart`
Core service handling all Supabase queries and file generation.

**Key methods:**
- `getCategoryCounts(String orgId)` — parallel `Future.wait` across all 18 tables for record counts
- `fetchTableData(String orgId, String tableName, {DateTime? start, DateTime? end})` — generic org-scoped fetch
- `generateCsvExport(String orgId, Set<String> categories, {DateTime? start, DateTime? end})` — UTF-8 BOM CSV with section headers per category, using `StatementFormatters.sanitizeForEncoding()`
- `generateExcelExport(String orgId, Set<String> categories, {DateTime? start, DateTime? end})` — one sheet per category with styled headers using `excel` package
- `generatePdfExport(String orgId, Set<String> categories, {DateTime? start, DateTime? end})` — org header + tabular sections using `pdf` package + `StatementFormatters`
- `getExportHistory(String orgId)` — wraps `ApiRepository.getExports()`
- `createExportRecord(...)` — wraps `ApiRepository.createExport()`
- `getScheduleSettings(String orgId)` — reads `organizations.settings['backup_schedule']` JSONB
- `updateScheduleSettings(String orgId, Map<String, dynamic> settings)` — writes to `organizations.settings` JSONB

**Pattern:** Reuses `StatementFormatters.money()`, `.date()`, `.sanitizeForEncoding()` from `core/utils/statement_formatters.dart`. CSV generation follows the UTF-8 BOM pattern from `transaction_csv_service.dart`.

### 2. `lib/features/settings/data/providers/backup_export_provider.dart`
Riverpod providers for the page state.

**Providers:**
- `backupServiceProvider` — `Provider.autoDispose<BackupExportService>` wrapping the service
- `categoryCountsProvider` — `FutureProvider.autoDispose<Map<String, int>>` for record counts per table
- `exportHistoryProvider` — `FutureProvider.autoDispose<List<Map<String, dynamic>>>` from `data_exports` table
- `selectedCategoriesProvider` — `StateProvider<Set<BackupCategory>>` for multi-select category grid
- `backupFormatProvider` — `StateProvider<StatementFormat>` defaulting to CSV
- `backupDateRangeProvider` — `StateProvider<DateTimeRange?>` for optional date filter
- `backupOptionsProvider` — `StateProvider<BackupOptions>` for encryption/compression/prefix settings
- `backupProgressProvider` — `StateProvider<BackupProgress>` enum: idle/generating/sharing/done/failed
- `scheduleEnabledProvider` — `FutureProvider<bool>` from org settings
- `scheduleConfigProvider` — `FutureProvider<Map<String, dynamic>>` from org settings
- `triggerBackupProvider` — Notifier that orchestrates: create export record → fetch data → generate file → share → update status

**Data model:**
```dart
enum BackupCategory {
  members, loans, emiSchedule, savings, savingsPlans, transactions,
  collections, savingsCollections, branches, staff, activityLogs,
  visitLogs, cashDeposits, walletTransactions, streaks, achievements,
  offlineQueue, syncConflicts
}

class BackupOptions {
  final bool encrypt;
  final bool compress;
  final bool includeSoftDeleted;
  final String? filenamePrefix;
}

enum BackupProgress { idle, generating, sharing, done, failed }
```
