## Part A: Security & Compliance (4 features)

All 4 features store config in `organizations.settings` JSONB under a `security` sub-key. This follows the same pattern as `communications`, `whatsapp`, and `payment_gateways`.

### Data Model

Add to `organizations.settings`:
```json
{
  "security": {
    "password_policy": {
      "min_length": 8,
      "require_uppercase": true,
      "require_lowercase": true,
      "require_numbers": true,
      "require_special_chars": true,
      "max_age_days": 90,
      "recycle_buffer": 5
    },
    "session_policy": {
      "idle_timeout_minutes": 30,
      "max_login_retries": 5,
      "lockout_duration_minutes": 15
    },
    "two_factor": {
      "enabled": false,
      "method": "totp",
      "enforced_for_roles": ["executive_admin", "branch_manager"]
    },
    "audit_retention": {
      "retention_years": 7,
      "auto_archive": false
    }
  }
}
```

### Files to Create

1. **`lib/features/settings/data/services/security_policy_service.dart`**
   - Class: `SecurityPolicyService(SupabaseClient client, String orgId)`
   - Methods: `getSecurityPolicy()`, `savePasswordPolicy(...)`, `saveSessionPolicy(...)`, `saveTwoFactorPolicy(...)`, `saveAuditRetention(...)`
   - Pattern: same as `EmailSettingsService` — reads `organizations.settings['security']`, merges sub-key, writes back

2. **`lib/features/settings/data/providers/security_policy_providers.dart`**
   - `securityPolicyServiceProvider` — `Provider<SecurityPolicyService>`
   - `securityPolicyProvider` — `FutureProvider<Map<String, dynamic>>` for current config
   - Pattern: same as `integrations_providers.dart`

3. **`lib/features/settings/presentation/pages/password_policy_page.dart`**
   - Form page with sliders/switches for: min length (4–32), require uppercase, lowercase, numbers, special chars, max password age (days), recycle buffer
   - Uses `_Section` + `_OrgTextField` + `Switch.adaptive` pattern
   - Save button persists to `security.password_policy`

4. **`lib/features/settings/presentation/pages/session_policy_page.dart`**
   - Form page with: idle timeout (5–120 min slider), max login retries (3–10), lockout duration (5–60 min)
   - Uses `_Section` + `_OrgDropdown` + slider widgets
   - Save button persists to `security.session_policy`

5. **`lib/features/settings/presentation/pages/two_factor_policy_page.dart`**
   - Toggle to enable/disable 2FA
   - Method selector: TOTP (Google Authenticator) or SMS-based
   - Role enforcement checkboxes (executive admin, branch manager, staff)
   - Save button persists to `security.two_factor`

6. **`lib/features/settings/presentation/pages/audit_retention_page.dart`**
   - Retention period dropdown (1–10 years, or "indefinite")
   - Auto-archive toggle
   - Info card explaining compliance implications
   - Save button persists to `security.audit_retention`

### Files to Modify

7. **`lib/features/settings/presentation/pages/security_compliance_page.dart`**
   - Convert 4 `_buildPolicyCard` stubs to `_buildTappablePolicyCard` with navigation:
     - Password Complexity → `/settings/security/password-policy`
     - Auto-Logout & Locks → `/settings/security/session-policy`
     - Two-Factor Authentication → `/settings/security/two-factor`
     - Audit Log Retention → `/settings/security/audit-retention`

8. **`lib/router/app_router.dart`**

     - `/settings/security/session-policy` → `SessionPolicyPage`
     - `/settings/security/two-factor` → `TwoFactorPolicyPage`
     - `/settings/security/audit-retention` → `AuditRetentionPage`

## Part B: Utilities & Support (3 features)

### Feature 5: Help Center & FAQs

A static content page with searchable FAQ categories. No backend needed.

#### Files to Create

### Feature 6: Report a System Glitch (Support Ticketing)

Reuse the existing customer support ticket infrastructure. The executive admin needs their own ticket creation view that uses the same `customer_support_tickets` table.

#### Files to Create

12. **`lib/features/settings/presentation/pages/support_ticketing_page.dart`**
   - Header with "Report a System Glitch" title
   - Create ticket form: subject, description (multiline), priority selector (low/normal/high/urgent), optional screenshot attachment
   - List of existing tickets from this user with status badges (open/in_progress/resolved)
   - Tap ticket to view conversation thread
   - Reuses `customer_support_tickets` and `customer_ticket_messages` Supabase tables
   - Pattern: simplified version of `customer_support_page.dart` (1765 lines) but for admin context — less KPIs, more focused on creation and tracking

13. **`lib/features/settings/data/services/admin_ticket_service.dart`**
   - Class: `AdminTicketService(SupabaseClient client, String userId, String orgId)`
   - Methods: `getMyTickets()`, `createTicket(...)`, `getTicketMessages(ticketId)`, `addMessage(ticketId, message)`
   - Uses same Supabase tables as `CustomerSupportRepository` but scoped to executive admin user

#### Files to Modify

14. **`lib/features/settings/presentation/pages/settings_page_v2.dart`**
    - In `_showSupportDialog()`, change "Report a System Glitch" `onTap` to navigate to `/settings/support-tickets` instead of `_showComingSoon`

15. **`lib/router/app_router.dart`**
    - Add route: `/settings/support-tickets` → `SupportTicketingPage`

### Feature 7: Privacy Policy & Terms

Static content page showing legal documents. Org-editable via settings JSON.

#### Files to Create

16. **`lib/features/settings/presentation/pages/legal_policies_page.dart`**
   - Tab bar: Privacy Policy | Terms of Service | About
   - Each tab renders formatted text content from `organizations.settings['legal']`
   - Default content provided for new orgs (standard privacy policy and ToS templates)
   - "Last updated" timestamp shown
   - Uses `GlassCard` containers with readable typography

17. **`lib/features/settings/data/services/legal_content_service.dart`**
   - Class: `LegalContentService(SupabaseClient client, String orgId)`
   - Methods: `getLegalContent()`, `saveLegalContent(type, content)`
   - Stores in `organizations.settings['legal']` as `{ privacy_policy: String, terms_of_service: String, last_updated: String }`
   - Provides default template content on first load

#### Files to Modify

18. **`lib/features/settings/presentation/pages/settings_page_v2.dart`**
    - In `_showSupportDialog()`, change "Privacy Policy & Terms" `onTap` to navigate to `/settings/legal` instead of `_showComingSoon`

    - Add route: `/settings/legal` → `LegalPoliciesPage`
