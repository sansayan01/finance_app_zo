# PDF Report for Today's Payments

## Goal
Replace CSV/text export with a professional PDF report across all 3 portals. Offer both "Preview PDF" and "Share PDF" options.

## Files to Create/Modify

| File | Action |
|------|--------|
| `lib/features/payments/data/services/payment_pdf_service.dart` | **CREATE** — new PDF service |
| `lib/features/payments/data/utils/payment_export.dart` | **MODIFY** — remove CSV/text, add PDF methods |
| `lib/features/payments/presentation/pages/today_payments_page.dart` | **MODIFY** — update share sheet |
| `lib/features/branch_manager/presentation/pages/branch_today_payments_page.dart` | **MODIFY** — update share sheet |

## Implementation

### Step 1: Create `PaymentPdfService`

**Path**: `lib/features/payments/data/services/payment_pdf_service.dart`

Follow the exact pattern from `TransactionPdfService`:

- Font loading: Inter fonts with Helvetica fallback + `_isValidFontData` check
- Use `StatementColors` for brand palette
- Use `StatementFormatters` for money(), date(), sanitizeForEncoding()
- Use `StatementOrgInfo` for org header

**Public API**:
```dart
class PaymentPdfService {
  /// Generate PDF bytes for preview
  static Future<Uint8List> generate({
    required TodayPaymentData data,
    required String dateLabel,
    StatementOrgInfo? orgInfo,
  });

  /// Generate + write to temp + share via system share sheet
  static Future<void> share({
    required TodayPaymentData data,
    required String dateLabel,
    StatementOrgInfo? orgInfo,
  });
}
```

**PDF Layout** (landscape A4 for table width):

**Page 1 — Header + Summary**:
- Org logo (if available) + org name + tagline
- "Payments Report" title
- Date label + "Generated on {timestamp}"
- Summary panel (4 stat cards in a row):
  - Total Due (₹amount, count)
  - Collected (₹amount, count, rate%)
  - Pending (₹amount, count)
  - Overdue (₹amount, count)

**Page 1+ — Detailed Table**:
- Columns: #, Customer, Type, Loan/Plan, Amount Due, Penalty, Collected, Status, Payment Mode, Due Date
- Row backgrounds alternate (grey50 / white)
- Status column uses semantic colors (green=collected, red=overdue, orange=pending)
- Type column shows "EMI" or "Savings" with type-specific color chip
- Table header uses navy900 background with white text

**Footer on every page**:
- "Page X of Y" centered
- "Generated by MicroFlow Pro" right-aligned

### Step 2: Update `payment_export.dart`

Replace CSV/text methods with PDF wrappers:
```dart
class PaymentExport {
  static Future<Uint8List> generatePdf(TodayPaymentData data, String dateLabel) =>
      PaymentPdfService.generate(data: data, dateLabel: dateLabel);

  static Future<void> sharePdf(TodayPaymentData data, String dateLabel) =>
      PaymentPdfService.share(data: data, dateLabel: dateLabel);
}
```

Remove: `shareCsv`, `_generateCsv`, `generateSummaryText`

### Step 3: Update share sheet in all 3 portals

Replace the 3-option sheet (Share Summary / Export CSV / Copy Summary) with a 2-option sheet:

```
┌──────────────────────────────┐
│  Export & Share              │
│                              │
│  👁 Preview PDF              │
│  View the report before sharing │
│                              │
│  📄 Share PDF                │
│  Generate and share via any app │
│                              │
└──────────────────────────────┘
```

**Preview action**: Call `Printing.layoutPdf()` with the generated bytes — shows native PDF preview with print/save/share controls.

**Share action**: Call `PaymentExport.sharePdf()` — generates PDF, writes to temp, opens system share sheet.

### Step 4: Fetch org info for PDF header

In each portal's share sheet callbacks, fetch org info from Supabase before generating PDF:
```dart
final orgInfo = await _fetchOrgInfo(ref);
// then pass to PaymentPdfService.generate(data: data, dateLabel: label, orgInfo: orgInfo)
```

Add a helper `_fetchOrgInfo` that queries the `organizations` table for name, logo, address, etc. This pattern is already used in the transaction PDF flow.
